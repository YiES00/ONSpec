# 검증 방법론 (공개 문서)

이 문서는 사이트에 게시되는 사양 값이 어떻게 수집·검증·등급화되는지 전부 공개한다.
방법론의 투명성이 이 데이터베이스의 신뢰 기반이다.

## 1. 데이터 3원칙

1. **출처 없는 데이터는 존재할 수 없다.** 모든 사양 값은 출처 레코드에 연결되며(DB 제약조건으로 강제),
   수집 시점의 원문 발췌를 함께 보존한다. 링크가 사라져도 근거는 남는다.
2. **조건 없는 성능 수치는 비교할 수 없다.** 추력·전류·방전율 같은 성능형 사양은
   측정 조건(프로펠러, 전압, 지속시간 등)을 구조화해 저장하고, 조건이 다르거나 없는 값은 표시에서 구분한다.
3. **모든 수치는 신뢰도 등급을 갖는다.** 등급은 제품이 아니라 **사양 필드 단위**로 부여한다.
   같은 제품이라도 "무게는 B, 최대추력 주장은 D"일 수 있다.

## 2. 출처 4계층과 가중치

| 계층 | 성격 | 기본 신뢰 가중치 |
|------|------|-----------------|
| S1 제조사 공식 | 제품 페이지·데이터시트 | 1.0 |
| S2 유통·판매처 | 리스팅 사양·가격 | 0.3~0.8 (판매처별 이력 기반) |
| S3 독립 실측 | 스러스트 스탠드·실용량 테스트 | 0.9 (값 자체는 실측 → A등급 후보) |
| S4 인증·규제 DB | FCC/KC 시험성적서 | 1.0 (실측 출력·생산지의 공적 근거) |

대표값은 가중치가 가장 높은 출처의 값으로 하되, **마켓플레이스 리스팅 값은 단독으로
C등급을 넘을 수 없다.** 가중 불일치가 임계를 넘으면 대표값과 함께 모든 출처 값을 병기한다.

## 3. 등급 정의

| 등급 | 의미 | 부여 조건 |
|------|------|----------|
| **A** | 실측 검증 | S3/S4의 독립 실측 데이터와 일치 확인 |
| **B** | 제조사 공식 | S1/S4 출처 + 자동 검증 전부 통과 |
| **C** | 미검증/조건 불명 | S2 출처만 존재, 또는 주의(caution) 판정 발생 |
| **D** | 플래그 | 물리 규칙 위반, 출처 간 중대 불일치, 논리 모순 |

D등급 값은 숨기지 않고 **사유와 함께 그대로 표시**한다. 과장 사양의 존재 자체가 정보다.

## 4. 자동 검증 규칙

### 물리 타당성 (1단계)

| 규칙 | 대상 | 내용 | 임계 |
|------|------|------|------|
| R-M1 | 모터 최대추력 | 모멘텀 이론: 이상적 소요출력 P=T^1.5/√(2ρA) 대비 표기출력으로 역산한 FoM | >1.0 플래그, >0.85 주의 |
| R-M2 | 모터 최대출력 | 출력 ↔ 최대전류×최대전압 정합 | 편차 >25% 주의 |
| R-M4 | 모터 무게 | 표기 무게의 부피 대비 밀도(스테이터 치수만 있으면 외피 ×4 보정) | >9,000kg/m³(강철 초과) 플래그 |
| R-M5 | 모터 전압 | 소형 클래스 비상식 전압(>61V), KV값과 동일하면 혼동 오기로 판정 | 플래그 |
| R-E1 | ESC 전류 | 순간 전류 < 연속 전류는 논리 오류 | 오류 |
| R-E2 | ESC 순간전류 | 지속시간 조건 미기재(원칙 2) | 주의 |
| R-E3 | ESC 전압 | 지원 셀수(만충 ×4.2V) ↔ 표기 전압 정합 | 편차 >5% 주의 |
| R-B1 | 배터리 | 에너지밀도 = 용량×정격전압÷무게 | >260Wh/kg 플래그, >200 주의 |
| R-B2 | 배터리 | 정격전압÷3.7V = 셀수 정합 | 불일치 플래그 |
| R-B3 | 배터리 | 대용량 팩의 과도한 연속 C율 | >60C 주의 |
| R-P1 | 프로펠러 | 피치/직경비 | >1.2 주의 |
| R-P2 | 프로펠러 | 직경 대비 무게 통상 대역 | 0.6D~8D(g) 밖 주의 |
| R-N1 | 공통 | 정규화 단계의 단위 오기 감지(예: 피치 '°' 표기) | 주의 |

상수: 공기밀도 ρ=1.225kg/m³(해수면). FoM(Figure of Merit)은 로터 효율 지표로 1.0이
이상적 한계이며 소형 로터 실측치는 통상 0.5~0.7이다.

### 교차 출처 대조 (2단계)

- **R-X1** 수치: 동일 사양의 출처 간 편차를 신뢰 가중 평균 대비로 계산.
  >15% 플래그, 5~15% 주의. 어느 경우든 모든 출처 값을 병기한다.
- **R-X2** 텍스트: 표기 불일치 시 주의 + 전 표기 병기(대표값은 가중치 상위 출처).

### 실측 연계 (3단계)

S3(스러스트 스탠드, 실용량 테스트)·S4(FCC 시험성적서의 실측 출력) 데이터를 해당
필드에 연결해 A등급을 부여하고 주장 대비 편차를 공개한다. **현재 데모 데이터에는
실측 연계가 없어 A등급이 존재하지 않는다** — Phase 1 운영 목표.

## 5. 파생값

에너지(Wh)·에너지밀도(Wh/kg)는 용량×정격전압(÷무게)으로 계산하며, 입력 필드들의
**최저 등급을 물려받고** 계산값임을 명시한다.

## 6. 생산국 표기

브랜드 **본사국**과 실제 **생산국**을 분리한다. 생산국은 S4 인증 문서 등 공적 근거가
있을 때만 '확인', 판매 페이지 표기는 '주장(미검증)', 근거가 없으면 **'미확인'으로
정직하게 표기**한다.

## 7. 현재 데이터의 한계 (정직 고지)

- Phase 1 MVP 시드 데이터로, 부품 수가 적고 가격 시계열이 아직 축적되지 않았다.
- `2207 PowerBeast`는 검증 엔진 시연용 **합성 픽스처(실제 제품 아님)**로, 사이트에 명시된다.
- 자동 규칙의 임계값은 플래그율 5% 목표로 지속 튜닝한다(계획서 §5.5).
- 사람 리뷰 큐: 플래그 항목은 리뷰어 승인 전까지 D등급을 유지한다.
